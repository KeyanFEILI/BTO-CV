# BTO content contract

## Preserve wording and facts

The CV is the factual authority. User-provided final edits override previous drafts for that candidate. Default output is English; another language requires the user's instruction. Translate the content faithfully, while retaining employer names, proper names, identifiers, code paths and certificate titles. Never replace unfamiliar technical terminology with a narrower claim merely because it sounds more natural.

Clear English stays unchanged. Rephrasing is limited to necessary translation, correcting an actual error, integrating project context, removing redundant labels or exact repetition, and joining adjacent fragments about the same activity. Retain the original action, ownership, scope, qualifiers, clients, tools, quantities and date precision. Do not change "monitored" to "implemented", turn a project purpose into a delivered achievement, or change "across two systems" to "cross-domain" without evidence.

Inside an experience, integrate project context with the relevant responsibilities. Do not add a second "Objective"/"Interest" heading beneath Main responsibilities. Group short related fragments (e.g. meeting preparation, facilitation and minutes). Do not merge unrelated activities or separate projects solely to reduce bullet count. The same activity in distinct projects is not necessarily a duplicate; qualify its project scope. Technical environment lists may be consolidated within a role if every technology is retained. The generator reports duplicate bullets and redundant labels; it does not decide how to rewrite them.

Keep a private source-to-output checklist, including the reason for necessary wording changes. This is a content review, not a request to create another CV variant. Do not claim that structural checks validate the translation or source facts.

## Dates and qualifications

- Experience: `MM/YYYY - MM/YYYY` or `MM/YYYY - Present` when months exist. Source `May 2019 - September 2020` becomes `05/2019 - 09/2020`.
- Year-only dates remain `YYYY` or `YYYY - YYYY`. Mixed precision remains mixed. Never insert 01/01, an assumed month, or a start/end day to fill a gap.
- In `March - May 2019`, 2019 is explicitly shared. If the year cannot be established, clarify it rather than guessing across a year boundary.
- Education: `[supplied diploma/course or institution], [supplied institution/location] | [dates]`. Example: `MSc Computer Science, Example University, Example City | 2022 - 2024`.
- Certifications/training: `Certificate or course, supplied location | YYYY`. Put status and scores before the date separator. No supplied date means no invented date or separator.
- If the source names only a school and location, use `School name, Location | dates`. Do not invent a degree or insert unnecessary phrases such as "studies". Preserve user-approved education wording.

The builder normalizes explicit numeric boundary dates and experience month names. Translation and placement of a date embedded inside prose remain the agent's responsibility. A date inside an exam title (e.g. a product version) is part of its name, not metadata.

## IT skills

Use no more than four coherent categories appropriate to that candidate. Retain all tools and methods from the source skills section; include relevant supported tools from experience environments where useful. Do not infer proficiency from a mention. Category consolidation is organizational, not a reason to remove skills. A possible grouping is Identity and data; Programming and frameworks; Systems and platforms; Methods and testing. These titles are examples, not a compulsory taxonomy.

## Languages and exams

English language names; source order; one proficiency in one pair of parentheses; no text after the closing parenthesis. Only the following display labels are used. This is a BTO display convention, not an independent proficiency assessment:

| Supplied description | Display |
| --- | --- |
| Native, mother tongue, langue maternelle, bilingual, bilingue | Native |
| Fluent, C1, C2, courant, usage courant | Fluent |
| Professional, Full Professional, B2, B1, A2, A1, Basic, Intermediate, notions, bonnes notions, très bonnes notions | Professional |
| No supplied level | Language name only |

An explicit user correction takes precedence. Do not infer native status from nationality, a language name, or an exam score. Unknown or conflicting descriptions need source reconciliation or user clarification; never silently truncate them or upgrade them.

Move language exams/certificates into CERTIFICATIONS AND TRAINING once, retaining language context, the exact exam name and source level in that name, score, status and date. `French - B1 (DELF B1 certified, 2022)` becomes `French (Professional)` and `French - DELF B1 certified | 2022`. A planned or taken exam must not become an earned certificate. A test score alone must not set proficiency.
